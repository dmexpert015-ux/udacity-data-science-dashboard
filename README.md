# Data Science Dashboard — Software Engineering for Data Scientists

An interactive employee/team dashboard built from the official Udacity
`dsnd-dashboard-project` starter. It combines SQLite queries, a reusable Python
package, inherited FastHTML components, Matplotlib visualizations, and the
provided scikit-learn predictor.

## Install and run

Use Python 3.10–3.12. From this project's root directory:

```bash
python -m venv env
source env/bin/activate
python -m pip install -r requirements.txt
./start
```

Open http://localhost:5001. The starter FastHTML version requires the compatible
Fastcore, Fastlite and Starlette versions pinned in requirements.txt.
If another application uses port 5001, launch with `PORT=5002 ./start`.

## Dashboard

The initial page shows employee 1. Select Employee or Team to refresh the profile
selector; select a profile and click Submit. Profiles also have direct links:
`/employee/2` and `/team/2`.

- Cumulative line chart: sums positive and negative events by date, sorts dates,
  fills missing counts, and displays cumulative totals.
- Recruitment risk chart: uses the supplied predictor's positive-class
  `predict_proba` output. Employee view displays the employee probability;
  team view displays the mean probability over that team's employees.
- Notes table: profile-specific notes ordered by date.

The data and predictor are the provided educational assets. These outputs are
model estimates, not causal conclusions or employment recommendations.

## Architecture

`python-package/employee_events` is an installable SQL API. `QueryBase` inherits
`QueryMixin`; `Employee` and `Team` supply profile names and model inputs. Database
paths resolve relative to the package rather than the working directory. Numeric
IDs are validated and bound as query parameters.

`report/base_components` provides reusable form, table and chart primitives.
`report/combined_components` combines them into forms and layouts.
`report/dashboard.py` implements the requested subclassed report components,
profile routes, dropdown refresh and POST redirect. `assets/model.pkl` remains
the original course model. PNG embedding preserves chart transparency.

## Validation

```bash
python -m pytest -q
flake8 report python-package/employee_events python-package/setup.py tests --count
```

The submission includes actual local validation logs and HTML/chart exports in
`validation/`. Twenty tests cover database existence/schema, SQL totals against
independent queries, both feature schemas, real model probabilities, five report
pages, selector refresh, POST redirects and invalid profiles/forms. This local
validation is separate from Udacity reviewer assessment and workspace validation.

## Package distribution

```bash
python -m pip install setuptools wheel
cd python-package
python setup.py sdist bdist_wheel
```

The package includes its SQLite database and dependency manifest.
